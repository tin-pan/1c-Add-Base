# 1c-Add-Base: массовое добавление информационных баз в `ibases.v8i`

Графическое приложение (WPF) на PowerShell для добавления записей о базах 1С в файлы `ibases.v8i` на компьютерах пользователей домена Active Directory.

## 📋 Возможности

- Поиск пользователей в Active Directory по части `displayName` или `CN`.
- Поддержка неоднозначных результатов (если найдено несколько пользователей – выводится ошибка с перечислением).
- Проверка доступности компьютера (ping) перед изменением файла.
- Добавление новой базы в формате:
```
[Имя базы]
Connect=...
```
- **Безопасное поведение**: если файл `ibases.v8i` не существует по указанному пути – операция считается ошибкой, файл не создаётся.
- Фоновая обработка (UI не блокируется).
- Подробный лог с цветовой индикацией (✅ успех, ⚠️ предупреждение, ❌ ошибка).
- Итоговый отчёт с группировкой по статусам.
- Всплывающее уведомление по завершении.

## 🧰 Требования

- Windows с установленными **RSAT Tools** (модуль `ActiveDirectory`).
- PowerShell 5.1 или выше.
- Сетевой доступ к компьютерам пользователей (шара `C$`).
- Права на запись в `\\computer\c$\Users\user\AppData\Roaming\1C\1CEStart\`.

## 🚀 Установка и запуск

1. Скачайте файл скрипта (например, `Add-1CBase.ps1`).
2. При необходимости отключите политику выполнения:
 ```powershell
 Set-ExecutionPolicy Bypass -Scope Process
```
3. Запустите скрипт:
```powershell
.\Add-1CBase.ps1
```
## 🖥️ Использование

1. В поле «Список пользователей» введите строки поиска (по одной на строку).
    Каждая строка может быть частью displayName или cn пользователя в AD.

2. Заполните «Параметр Name» – имя базы, которое будет отображаться в списке (будет заключено в квадратные скобки).

3. Заполните «Параметр Base» – строка подключения, например:
    Connect=Srvr="server";Ref="Accounting";

4. Нажмите «Запустить».

5. Во время выполнения интерфейс остаётся отзывчивым, в лог выводится ход обработки.

6. По завершении появляется итоговый отчёт с разбивкой по каждому пользователю и общая статистика.

## ⚙️ Примечания

- Имя компьютера формируется по правилу: {SamAccountName}-h.

- Путь к файлу:
    \\{computer}\c$\Users\{SamAccountName}\AppData\Roaming\1C\1CEStart\ibases.v8i

- Если при проверке доступности компьютер не отвечает на ping – операция пропускается с ошибкой.

- Приложение однопоточное в части GUI, но вся работа с AD и файлами выполняется в фоновом Runspace.
